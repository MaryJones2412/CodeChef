## Problem

### String Operations

Let us finish this module with some more practice!

Write a program which does the following:

- Declare a string variable var.
- Assign the value "String" to it.
- And then print to the console the first 3 characters of the string. Do not include any space or new line.
- When you run the code, you will get a compilation error - go ahead and debug the code as well.

## Solution

**Language:** Java  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-03T01:00:12.654Z  

```java
class Codechef
{
	public static void main (String[] args)
	{
	   // Update the blank in code given below
		String var = "String";
        System.out.print(var.charAt(0));  // Print the first 3 characters
        System.out.print(var.charAt(1));
        System.out.print(var.charAt(2));
	}
}
```
